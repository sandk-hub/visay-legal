## Updating the policy

1. Update both Vietnamese and English sections in `index.html` or `terms.html`.
2. Update the effective date and metadata when the policy materially changes.
3. Open both `?lang=vi` and `?lang=en` locally and verify links and layout.
4. Push to `main`. The Pages workflow publishes the site automatically.

The site intentionally contains no analytics, advertising, forms, external fonts, or first-party cookies. The small language script stores only the visitor's selected language in local storage.
