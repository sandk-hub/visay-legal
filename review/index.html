Visay: user-initiated screen translation

Google Play review demonstration for FOREGROUND_SERVICE_MEDIA_PROJECTION.

Open or download the MP4 video

Recorded on a physical Android device on 8 October 2026. The app interface is Vietnamese; the demonstrated translation target is Japanese.

  1. The user opens Screen Translation in Visay.
  2. Android asks the user to approve sharing the screen.
  3. The user opens a public sample webpage in Chrome and taps the floating Visay button.
  4. Visay recognizes screen text and displays a Japanese translation overlay.
  5. The user closes the translation, opens the floating button controls, and stops screen translation. Android's screen-sharing indicator disappears.

The floating session maintains the authorized MediaProjection session while the user views another app. Captures are requested by the user using the floating button.
